# npcvalue

An Ashita v4 addon that shows what an NPC shop pays for items, right where you're looking at them:

- **The item under your cursor** in the game's item menus: your inventory and other bags, the mog safe and storage, equipment lists, trades, the delivery box, your bazaar and shop selling. For a stack it shows the price each and for the whole stack, and for an item in another bag it reminds you that only inventory items can be sold.
- **The treasure pool**: while the pool window is open, every item in it with its price. The item the game has selected is marked with `>`.

Items no shop will buy, and items shops pay nothing for, say so.

Nothing is ever sent to the server: npcvalue only reads client memory.

## Installation
- Download `npcvalue0.2.zip` from the [latest release](https://github.com/relliko/npcvalue/releases/latest) and extract it into your Ashita v4 directory (it contains `addons/npcvalue`).
- Type `/addon load npcvalue` in game.

## Usage
Open an item menu or the treasure pool and the price box appears. Drag it where you want it while it's showing.

| Command | |
|---|---|
| `/nv on\|off` | show or hide the price box (`/npcvalue` works too) |
| `/nv reset` | move the box back to where it starts |
| `/nv debug` | show the game's menu name, selected item and treasure pool slots, to report a menu the box misses |

## Where the prices come from
`data/prices.lua` is generated by `tools/gen_prices.py` from LandSandBoat's item table (`sql/item_basic.sql`, the BaseSell column). A shop pays that price adjusted by your fame with the shop's area, 97.5% to 102.5% of it, and at least 1 gil. Items with the NOSALE flag are refused by every shop.

To regenerate the data from a LandSandBoat checkout:
```
python tools/gen_prices.py --lsb C:\path\to\LSB
```
